# Student Performance Analysis

## 📌 Project Overview
This project analyzes student performance data to identify patterns and insights related to students' academic performance.

The project uses Excel for data preparation and Power BI for interactive data visualization and dashboard creation.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📊 Key Features
- Student performance analysis
- KPI cards
- Interactive dashboards
- Performance comparison
- Data filtering using slicers
- Visual analysis of student-related metrics

## 📂 Files Included
- `Student performance analysis project (5).pbix` – Power BI dashboard file
- `student_data_analysis_5001.xlsx` – Dataset used for analysis
- `student-performance-dashboard.png.png` – Dashboard screenshot
- `dashboard-overview.png.png` – Dashboard overview screenshot

## 🎯 Project Objective
The objective of this project is to analyze student performance data and present meaningful insights through an interactive Power BI dashboard.

## 📈 Project Outcome
The dashboard helps users understand student performance patterns and explore the data through interactive visualizations and filters.
